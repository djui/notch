Coding agents

One click to wire up.
Safe by design.

Open Settings → Coding Agents and click Install. Notch registers a tiny hook with each agent and keeps your existing hooks exactly as they were.

Claude Code~/.claude/settings.json
Codex~/.codex/hooks.json
Cursor~/.cursor/hooks.json
  • Never leaves your Mac. Events travel over a Unix socket only your user can open.
  • Can't block an agent. The hook always exits 0 without output.
  • Easy to undo. The previous config is kept as a .notch-backup.

Install

Up and running in a minute.

  1. 1

    Download

    Grab the latest Notch-1.4.0.zip from GitHub Releases.

    Download →
  2. 2

    Move to Applications

    Unzip and drag Notch.app into your /Applications folder.

  3. 3

    Open

    First launch walks you through permissions and turns on launch at login.

Notch is signed but not notarized. If macOS won't open it, clear the quarantine flag and try again:

xattr -cr /Applications/Notch.app
